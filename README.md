
A high-octane, dark-mode design template tailored for performance automotive brands and engineering studios.

## Features
* **Automotive Dark Aesthetic:* Engineered with high-contrast carbon and dark slate tones with performance highlights.
* **Interactive Scope Builder:* Custom configuration modules designed for tailored project scoping.
* **Instagram DM Dispatcher:* Seamless direct routing to `@zac.cosmos.engine`.

## Tech Stack
* HTML5, CSS3, Vanilla JavaScript.
